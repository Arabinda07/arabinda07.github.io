# Study App: Guided Online Tuition Platform

Live private web application for guided online Class 7 ICSE Maths and Science
tuition, connecting weekly class schedules, structured Concept Studio study
notes, school syllabus and doubts tracking, and 30-mark CISCE-style assessments
with misconception diagnostics and parent progress views.

- Status: live (private PIN-authenticated tuition workspace).
- Web app: https://stem-classes.vercel.app/
