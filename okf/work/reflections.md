# Reflections: Private Writing Journal

Live private writing journal on web and Android with client-side AES-256
encryption, offline-first persistence (Dexie + Supabase), and on-device vector
search (Echoes) that never sends note text to the cloud.

- Status: live on Web and Google Play.
- Google Play: https://play.google.com/store/apps/details?id=com.arabinda.reflections
- Web app: https://www.reflections-sanctuary.space/
